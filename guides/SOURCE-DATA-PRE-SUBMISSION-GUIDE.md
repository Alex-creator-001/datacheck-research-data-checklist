# How to Check Research Source Data Spreadsheets Before Journal Submission

1. **Scope:** Check raw Source Data files (`XLSX`, `CSV`, `TSV`) supporting figures, Supplementary Tables, ELISA/qPCR/Western Blot quantification, clinical Table 1 baselines, chromatography peak areas, battery cycling curves, or econometric panel tables.
2. **Distinguish verification from data cleaning:** Never overwrite or auto-delete suspected duplicates without tracing the original cell coordinates first. Legitimate shared controls or instrument detection limits can look like duplicates numerically.
3. **Inspect cross-sheet and reordered reuse:** Copy-paste errors often move values to another worksheet tab or reorder rows during sorting. Review the full workflow at [datacheck.cc Data Checking Guide](https://datacheck.cc/en/data-check-guide) and [Pre-Submission Checklist](https://datacheck.cc/en/research-data-checklist).
4. **Confidential unpublished datasets:** When institutional policy prohibits uploading unpublished tables to a web service, use offline local analysis on [datacheck.cc Windows Desktop](https://datacheck.cc/en/desktop).

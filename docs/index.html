Five-Step Pre-Submission Audit Workflow

  1. Freeze the submission workbook (XLSX, CSV, or TSV).
  2. Check within-sheet and cross-sheet duplicates (both exact sequences and reordered pools).
  3. Scan numerical anomalies across the 56 versioned rules (fixed multiples/offsets, shifted rows, decimal tails, digit distributions, statistical consistency).
  4. Trace every finding to source cells to distinguish legitimate shared controls from paste/sort errors.
  5. Record human review decisions in the downloadable CSV review log.

Frequently Asked Questions

How do you check research spreadsheets for cross-sheet duplicates before journal submission?
Compare both exact row sequences and reordered numeric value pools across tabs, then trace flagged coordinates back to source records. See cross-sheet duplicate verification and the data checking guide.
Does DataCheck use AI to flag data anomalies?
No. DataCheck applies 56 deterministic, versioned non-AI rules and outputs traceable source-cell leads for human review. Browse the full specification in the 56-rule catalog.
